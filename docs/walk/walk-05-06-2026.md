# Walkthrough: Implementasi Auto-Sync Bot Google Drive (05-06-2026)

## Deskripsi Singkat

Dokumen ini merangkum seluruh perubahan dan implementasi yang dilakukan untuk fitur **Sinkronisasi Otomatis Google Drive ke Ario Library**. Fitur ini memungkinkan aplikasi untuk membaca file PDF buku yang diunggah ke folder Google Drive dan secara otomatis mencatatnya sebagai `draft` di dalam database perpustakaan.

## Daftar Perubahan (Changes Made)

### 1. Penyesuaian Skema Database (Database Updates)

- Mengeksekusi penambahan *constraint* `UNIQUE` pada kolom `name` di tabel `categories` untuk mencegah duplikasi nama kategori.
- Menambahkan kolom `drive_file_id` (sebagai penanda unik setiap _file_ dari Google Drive) dan `status_entri` (dengan nilai default `draft`) pada tabel `books`.
- Memperbarui file SQL referensi di [db/setup.sql](file:///c:/laragon/www/ario_library/db/setup.sql) untuk menyimpan versi skema paling baru.

### 2. Pembaruan Komponen Inti (Core)

- Memperbarui file [app/core/Database.php](file:///c:/laragon/www/ario_library/app/core/Database.php) dengan menambahkan *method* `lastInsertId()`. Fungsi ini krusial untuk mengambil `id` Kategori yang baru saja dibuat agar dapat direlasikan langsung saat meng-insert data buku.

### 3. Pembuatan Webhook API (MVC)

- **Model**: Dibuat [app/models/Api_model.php](file:///c:/laragon/www/ario_library/app/models/Api_model.php) yang menangani dua *query* utama:
  - `insertCategoryIfNotExists` untuk mendata *folder* Drive sebagai kategori rak baru.
  - `insertBookDraft` untuk menyimpan detail buku yang baru saja disinkronkan menjadi _draft_.
- **Controller**: Dibuat [app/controllers/Api.php](file:///c:/laragon/www/ario_library/app/controllers/Api.php) yang memproses alamat _endpoint_ API (`/api/bot_sync`). Controller ini membaca _payload_ JSON dan memvalidasi keamanan _header_ menggunakan Bearer Token (`ARIO_SECRET_TOKEN_2026`).

### 4. Pembuatan Dokumentasi Konfigurasi Bot

- Membuat panduan instalasi lengkap layaknya dokumentasi untuk Junior Dev di file [GASSetting.md](file:///c:/laragon/www/ario_library/GASSetting.md). Panduan ini merinci *setup* Google Apps Script, mekanisme *triggering* tiap 5 menit, dan cara menyambungkannya dengan tunnel internet lokal menggunakan Ngrok.

## 🔒 Fitur Pembatasan Akses Buku Kadaluwarsa (Overdue)

Sesuai pembaruan tambahan, sistem telah dilengkapi dengan proteksi tambahan bagi peminjam yang melanggar batas waktu:

### 1. Blokir Paksa di Halaman Profil
- **File**: [app/views/member/profile.php](file:///c:/laragon/www/ario_library/app/views/member/profile.php)
- Jika pengguna masuk ke halaman Profil dan terdeteksi memiliki peminjaman _overdue_, sistem akan memunculkan sebuah _pop-up_ layar penuh menggunakan SweetAlert yang **tidak bisa ditutup** (`allowOutsideClick: false`, `allowEscapeKey: false`).
- Satu-satunya jalan keluar adalah menekan tombol yang akan memaksa (_force redirect_) pengguna menuju alamat `http://localhost/ario_library/public/loan` untuk melakukan aksi pengembalian buku.

### 2. Penutupan Akses _Viewer_ Buku
- **File**: [app/controllers/Book.php](file:///c:/laragon/www/ario_library/app/controllers/Book.php)
- Jika pengguna mem- _bypass_ dengan mencoba membuka _link_ baca/PDF secara langsung, fungsi `read($loan_id)` akan mendeteksi status `due_date`.
- Jika sudah lewat batas, maka sistem tidak akan me-_load_ _file_ Google Drive (iframe), melainkan langsung menendang pengguna ke halaman `/loan` disertai notifikasi penolakan akses.

## 🤖 Fitur Pengembalian Otomatis (Auto-Return > 15 Hari)

Berdasarkan pembaruan teranyar, sistem kini dapat mendeteksi dan menindak otomatis keterlambatan berat yang lebih dari 15 hari dari tanggal jatuh tempo. 

### 1. Engine Pemrosesan
- **File**: [app/models/Loan_model.php](file:///c:/laragon/www/ario_library/app/models/Loan_model.php)
- Saya telah membuat fungsi baru `processAutoReturn($userId)` yang bertugas untuk menyapu (_sweep_) seluruh riwayat buku yang di-_borrow_ oleh *user* bersangkutan. Jika durasi (`DATEDIFF`) melebihi 15 hari, buku akan dikembalikan secara paksa (`status = 'returned'`), stok akan bertambah, dan nama buku yang diproses akan di-ekstrak.

### 2. Trigger Terpusat
- **File**: [app/controllers/Member.php](file:///c:/laragon/www/ario_library/app/controllers/Member.php), [app/controllers/Loan.php](file:///c:/laragon/www/ario_library/app/controllers/Loan.php), [app/controllers/Home.php](file:///c:/laragon/www/ario_library/app/controllers/Home.php), dan [app/controllers/Book.php](file:///c:/laragon/www/ario_library/app/controllers/Book.php)
- Fungsi *auto-return* dipanggil di awal proses setiap kali anggota menjelajahi web. Ini memastikan *triggering* dilakukan tepat sebelum memuat tampilan antarmuka (_view_). Hasil ekstraksi (judul-judul buku) lalu disimpan sesaat di `$_SESSION['auto_return_alert']`.

### 3. Eksekusi Notifikasi Pop-Up (Alert)
- **File**: [app/views/templates/footer.php](file:///c:/laragon/www/ario_library/app/views/templates/footer.php)
- Jika *Session Alert* di atas aktif, _footer_ akan memuat _SweetAlert_ spesial berikon `info` dengan pesan yang sudah Anda tentukan, berisi rentetan nama judul buku yang dieksekusi, dan kemudian menghapus (_unset_) _session_ tersebut agar tidak muncul dua kali di halaman berikutnya.
